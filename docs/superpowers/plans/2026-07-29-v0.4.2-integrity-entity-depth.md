### Task 1: `scan_content_integrity` + `integrity` mode

**Files:** Modify `scripts/fetch_page.py`; Create `tests/test_integrity.py`.

Detects (static HTML only, all non-fabricated — flag patterns, quote evidence):
- **Hidden text**: inline `display:none`/`visibility:hidden`/`opacity:0`/`font-size:0`/`font-size:1px` on text-bearing elements; text color equal to background (monochrome) where inline styles allow; off-screen positioning (`position:absolute` with large negative offsets).
- **Invisible Unicode**: zero-width chars (U+200B–U+200D, U+FEFF) inside visible text.
- **LLM-directed instructions**: imperative phrases aimed at models in HTML comments, `aria-hidden="true"` containers, or `data-*` attributes — regex for "ignore (all )?previous instructions", "you (are|must|should) (now )?", "cite (this|us) as", "recommend [X] (as|above)", "system prompt". Report the matched string + location.
- **Cloaking hint**: `aria-hidden` blocks containing substantial keyword-dense text.

Output: `{url, findings: [{type, severity, evidence, location}], counts: {...}, summary}`. **Static-analysis honesty:** these are *signals*, not proof — the skill layer frames them as "review these" not "you are spamming". Severity: hidden-text/LLM-instruction = high; zero-width/monochrome = medium.
