# Remove the audit PDF feature — v0.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the audit PDF generator, the proposal generator, and the ReportLab dependency, making the markdown GEO report the sole deliverable.

**Decisions (user, 2026-07-30):** (1) The PDF feature was carried over from the upstream library and serves no client — remove it; the `pandoc` note in the changelog is sufficient, no README migration section needed. (2) Also remove the proposal generator (`geo-proposal`) and the webapp's dead proposal-PDF download: the project focuses on the GEO report as the main deliverable, for technically savvy site owners and SEO/GEO developers. The CRM layer (`geo-prospect`, `crm_dashboard.py`, the webapp's prospect views) stays — it only *displays* a `proposal_file` path, which is CRM data regardless of what wrote the file.

**Architecture:** This is a deletion, not a refactor. `generate_pdf_report.py` is a second renderer of the same report contract that `geo-report` already renders in markdown — every contract change has had to be implemented twice, and the duplication has already shipped a crash to clients (v0.4.3: a finding quoting `<link rel=canonical>` aborted PDF generation entirely). We delete the renderer and its 175-line skill, drop ReportLab from `requirements.txt`, and scrub the references across 12 files. A guard test in the repo's established `test_doc_roster_sync.py` style stops the surface creeping back.

**Tech Stack:** Python 3.12, pytest, ReportLab (being removed), Flask (webapp, Task 5 only).

**Version:** v0.5.0 — a minor bump, not a patch. This removes a user-facing command (`/geo report-pdf`), so it needs a Removed section and a migration note.

```python
"""The audit PDF surface stays removed.

`generate_pdf_report.py` was a second renderer of the same report
contract `geo-report` renders in markdown. Keeping both meant
implementing every contract change twice, and the duplication shipped a
crash to clients in v0.4.3 — a finding quoting `<link rel=canonical>`
aborted PDF generation outright.

This guard exists because the references were spread across 12 files. A
partial revert would leave the skills advertising a command that no
longer exists, which is worse than either keeping or removing it.
"""

import os
import re

REPO = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))

# Files scanned for dangling references to the removed surface.
SCANNED = (
    "README.md",
    "CLAUDE.md",
    "CONTRIBUTING.md",
    "install.sh",
    "install-win.sh",
    "requirements.txt",
    "evals/report-contract-scenarios.md",
    ".claude-plugin/plugin.json",
    ".claude-plugin/marketplace.json",
    "skills/geo/SKILL.md",
    "skills/geo-audit/SKILL.md",
    "skills/geo-compare/SKILL.md",
    "skills/geo-proposal/SKILL.md",
    "skills/geo-reporter-setup/SKILL.md",
    "skills/geo-report/SKILL.md",
)

# Naming the removed surface. "PDF" alone is deliberately NOT a pattern:
# geo-audit legitimately says it skips PDFs as crawl input.
FORBIDDEN = (
    re.compile(r"generate_pdf_report"),
    re.compile(r"report-pdf"),
    re.compile(r"reportlab", re.IGNORECASE),
)


def _read(rel):
    path = os.path.join(REPO, rel)
    if not os.path.exists(path):
        return None
    with open(path, encoding="utf-8") as handle:
        return handle.read()


class TestRemovedFilesStayRemoved:
    def test_generator_is_gone(self):
        assert not os.path.exists(
            os.path.join(REPO, "scripts", "generate_pdf_report.py"))

    def test_skill_is_gone(self):
        assert not os.path.exists(
            os.path.join(REPO, "skills", "geo-report-pdf"))

    def test_its_tests_are_gone(self):
        assert not os.path.exists(
            os.path.join(REPO, "tests", "test_pdf_tldr.py"))


class TestNoDanglingReferences:
    def test_no_file_names_the_removed_surface(self):
        offenders = []
        for rel in SCANNED:
            content = _read(rel)
            if content is None:
                continue
            for line_no, line in enumerate(content.splitlines(), 1):
                for pattern in FORBIDDEN:
                    if pattern.search(line):
                        offenders.append(f"{rel}:{line_no}: {line.strip()}")
        assert not offenders, (
            "these still advertise a command that no longer exists:\n"
            + "\n".join(offenders)
        )

    def test_reportlab_is_not_a_dependency(self):
        assert "reportlab" not in (_read("requirements.txt") or "").lower()


class TestUnrelatedPdfMentionsSurvive:
    """The word "PDF" is not itself forbidden.

    geo-audit tells the crawler to skip PDFs as input. Scrubbing that
    while removing the generator would change crawl behaviour, which is
    not what this release is for.
    """

    def test_geo_audit_still_skips_pdf_input(self):
        content = _read("skills/geo-audit/SKILL.md") or ""
        assert "Skip PDFs" in content
```
